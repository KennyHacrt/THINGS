# Submission note: desktop application

THINGS runs as a Windows desktop application because it needs access to task windows, local speech recognition and desktop input. It cannot be used through a web page alone. Reviewers can download the Windows build from GitHub Releases, open it and enter their own API settings on the first screen. The repository also includes source setup instructions, and the demo video shows the desktop interaction.

The organiser's mobile-app announcement does not explicitly cover Windows desktop apps. Do not state that it grants this project a prototype-link exemption. Include the Windows download, repository and video, and confirm the accepted prototype-link format with the organiser if needed.
