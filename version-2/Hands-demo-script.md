# Hands: General Learning Hackathon

[Watch the demo on YouTube](https://www.youtube.com/watch?v=0iIoCPmOIKc) · [Hands source code](https://github.com/lithdew/hands) · [Original timestamped captions](Hands-YouTube-transcript.txt)

The following script covers all the speech in YouTube’s English caption track. Paragraphs follow the first caption in each passage. Punctuation, names and apparent caption errors have been edited using the uploader’s description. The performance and cost figures are the speaker’s claims about Hands.

**0:04** There’s a lot of times we feel a little light-handed. Things like booking flights, ordering food online, or staying up to date with what’s new on X. All these things take up a lot of time out of our day.

**0:16** Which is why we built Hands. We envisioned a user experience where people could hold down a key, voice out their frustration, and offload whatever they were working on to one, two, or several hands.

**0:33** Powering a single hand is a computer use integration from scratch that is 150 times cheaper and 14 to 40 times faster than commercial computer use integrations.

**0:46** Our computer use integration is powered by TypeSafe AI’s Jev and reverse-engineered foreign function interface bindings to private native system frameworks, such as SkyLight in macOS. Just a single computer use interaction, on average, costs just $0.0002.

**1:06** When a task requires deep intelligence, your hand will delegate its work off to frontier large language models. Our hand agent’s core is built on top of the pi coding agent and therefore supports all of the frontier lab models and subscriptions, of course, only for personal use.
